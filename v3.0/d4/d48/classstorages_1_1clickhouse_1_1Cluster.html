const Query & query,
const Args &... args ) const

Execute a statement with specified command control settings at some host of the cluster with args as query parameters.

It is convenient to keep SQL queries in separate files, see Embedding SQL/YQL files via userver_add_sql_library for more info.

Example usage:

const storages::clickhouse::Query q{"SELECT {}, * FROM system.numbers limit {}"};
const auto result = cluster->Execute(q, "we", 5).As<DataWithValues>();
EXPECT_EQ(result.values.size(), 5);
EXPECT_EQ(result.strings.size(), 5);
EXPECT_EQ(result.strings.front(), "we");

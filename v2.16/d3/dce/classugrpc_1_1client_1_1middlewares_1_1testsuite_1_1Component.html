Detailed Description

Component for gRPC client testsuite support.

The component supports testsuite errors thrown from the mockserver, such as NetworkError, TimeoutError.

See also
grpc_mockserver
pytest_userver.grpc.TimeoutError
pytest_userver.grpc.NetworkError

The component does not have any options for service config.

See also
gRPC client middlewares

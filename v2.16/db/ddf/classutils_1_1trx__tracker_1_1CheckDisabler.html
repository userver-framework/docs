Detailed Description

Disable check for active transactions.

To consciously call a heavy operation in active transaction, check can be disabled by creating an instance of this class. Checks will be disabled until every instance either has Reenable() method called or is destroyed.

auto trx = cluster.Begin();
{
utils::trx_tracker::CheckDisabler disabler;
client.SomeHandle(request); // calls utils::trx_tracker::CheckNoTransactions()
}
trx.Commit();

Detailed Description

For some unclear reasons almost all fields in S3 API are optional including even those fields which are clearly stated to be required in S3 documentation. There are some unconvincing explanations for this at https://github.com/boto/botocore/issues/1069#issuecomment-259255047, but that's it! This implementation of the API in this library is a bit stricter than it is in S3 API specifciation, intentionally making some optional fields to be required non-empty.

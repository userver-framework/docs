Waits for some external event for total_wait_seconds and calls check every relax_period_seconds.

If check returns False or raises NotReady exception (or any exception type referenced in catch), the waiting continues. If check returns True, wait_until() stops and returns. After total_wait_seconds of unsuccesfull checks wait_until() raises TimeoutError.

Example:

.. code-block:: python 

async def is_ready():
    return await conn.is_ready()

await wait_until(try_to_connect_db)
Exceptions
TimeoutErrorafter total_wait_seconds of unsuccesfull checks
Note
If possible, use testpoint instead. testpoint is an explicit message from the server "I'm ready", while wait_until() uses an implicit idea "A condition is met, so I can continue".

Waits for some external event for total_wait_seconds and calls func every relax_period_seconds.

If func raises NotReady exception, the waiting continues. If func succesfully returns, wait_until() returns the same value. After total_wait_seconds of unsuccesfull checks wait_until() raises TimeoutError.

Example:

.. code-block:: python 

async def try_to_connect_db():
    if not db_conn_is_ok():
        raise NotReady()

await wait_until(try_to_connect_db)
Exceptions
TimeoutErrorafter total_wait_seconds of unsuccesfull checks
Note
If possible, use testpoint instead. testpoint is an explicit message from the server "I'm ready", while wait_until() uses an implicit idea "A condition is met, so I can continue".
